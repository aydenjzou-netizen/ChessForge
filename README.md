# Chess PGN Viewer with AI Explanations

A lightweight, local, completely browser-driven Chess PGN viewer, integrated with a local Ollama AI model (Phi-3 Mini) to explain chess moves on demand.

## Features
- **Frontend PGN Parsing:** Built entirely with `chess.js` and `chessboard.js`.
- **No Heavy Backend Rules:** `python-chess` has been removed. The backend is just a simple API to route chat messages.
- **Local AI Explanations:** Sends the current FEN, selected move, and game history to a local `phi3:mini` model through Ollama to generate context-aware chess explanations.

## Requirements

1. Python 3.9+
2. Ollama running locally

## Installation

Install the minimal backend requirements:
```bash
pip install -r requirements.txt
```

### Install the AI Model
You must have Ollama installed and running on your machine.
1. Download Ollama from [ollama.com](https://ollama.com).
2. Start the Ollama server:
   ```bash
   ollama serve
   ```
3. Pull the required model in a separate terminal:
   ```bash
   ollama pull phi3:mini
   ```

## Running the App

Start the FastAPI application:
```bash
python main.py
```
Then navigate to `http://localhost:8001` in your browser.

## How the AI Integration Works

When you upload a PGN and select a move, the frontend gathers context:
- The current **FEN** generated by `chess.js`
- The selected **Move** (SAN format)
- The **Move Number**
- A slice of the **Move History** around the current position

This context is sent to the backend `/api/chat` route, which builds a prompt and queries `http://localhost:11434/api/generate`.

### Manual Ollama Test
If you want to test if your Ollama model is working properly without the app, run:
```bash
curl http://localhost:11434/api/generate -d '{
  "model": "phi3:mini",
  "prompt": "Explain what 1. e4 does in chess.",
  "stream": false
}'
```
